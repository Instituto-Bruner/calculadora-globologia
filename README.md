# Calculadora Profesional de Globología

Aplicación web de Instituto Bruner × Happy Deco para calcular costos, presupuestos y rentabilidad de decoraciones con globos.

## Abrir localmente

Abrí `index.html` con cualquier navegador moderno. No requiere instalación, servidor, cuenta ni conexión a internet.

## Uso

La aplicación incluye Cálculo Rápido, Cálculo Básico y Rentabilidad como recorridos principales. El Manual de uso integrado explica el proceso completo, desde la configuración inicial hasta la impresión del presupuesto para el cliente.

## Datos

Los materiales, configuraciones y presupuestos se guardan en `localStorage`, es decir, en el navegador y dispositivo utilizados. No se sincronizan automáticamente entre personas o equipos. Para trasladarlos, usá **Configuración → Exportar copia de seguridad** e importá el archivo en el otro dispositivo.

## Publicación

El proyecto es completamente estático y compatible con GitHub Pages.
